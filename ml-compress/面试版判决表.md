# ml-compress 面试版判决表（一页）

用法：左列是可以照着说的一句话，中列是它**只在哪些坐标下成立**，右列是**哪一发立的、哪一发动过它**。
搬用坐标外的话，就是这张表要防的那件事。读数全部出自同目录的 `compress_report_v*.json`，可现读复核。

## 三、三句口径（被追问时先交这三句）

- **单位**：效应一律报"多少张 + 该档自己的底倍数"，不报 pp——同一套仪器在 Fashion 上的种子底是 MNIST 的 2.6~2.9 倍。
- **独立性有八种**：换种子 / 换宽度 / 换老师 / 换任务 / 换样本批次 / 换机器状态 / **换温度列** / **换学生架构族**（第八维 = 第二十一发，MLP → 与老师同族的 CNN；前七维买的都是"同一副学生换个条件"，这一维换的是表达式形状本身）。（最后这一维本轮一次用了三回，见下面那三条 `_t6` 判决）。n=8 那批发买的是**分辨率**，不是独立性；本轮往中数据档再加四条流（n=12）买的**还是**分辨率——同一批图、同一个老师、同一个训练器，所以那一发**不许被写成"倒挂被复证了"**。账要按买到的那一维报；而"我登记了守卫会验这一条"和"那道闸真的看得见这一对"也是两件事——本轮为把它们分清，在 282 秒的训练之外又重跑了九档拆红。第三种买法本轮也出现了一次：`--ladder-high` 那发**既不买分辨率也不买独立性**，它买的是"没测过的坐标段"（α>0.7 那两格，仍在那 8 条流上）⇒ 账上多的是**覆盖**，判据吃的一个字没动。**代价也在这里现形**：那一发第一次真跑把 64 次训练全烧完之后才死于一个 `KeyError: 1.0`（`by_seed`
