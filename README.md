## 跨项目方法论（踩出来的）

1. **泄漏是头号公敌**：时间泄漏/元数据泄漏/评估泄漏，每个项目用对照实验量化一次
2. **指标反常 = 流程警报**，先审计后庆祝（时序课因此发现多步预测标签泄漏）
3. **误差分析决定投资方向**：分片、混淆对、置信度分层收益 > 换模型
4. **train/serve 一致性**：一套预处理从训练用到线上（增强不对齐分布时是毒药，有实验）
5. **上线三件套**：置信度阈值 + 输入护栏 + 拒答转人工
6. **评估工具也是被测对象**：RAG 首轮输给裸考，查出的问题是提示词和判卷官自己；judge 全给满分是量表饱和，不是完美
7. **墙钟数字必须先量仪器自己的分辨率**：同一份权重测两遍当对照臂，噪声底压不住差异就不许下结论；"一臂跑完再跑下一臂"能漂 4.3 倍，同进程交错配对能压到 1.15 倍——坏的是估计算法，不是延迟这个指标。逐条追加（**这一串故意不数条数**：上一版写"六条追加"时底下已经挂着七条，连"几条"这种最该确定的数都会腐烂）：**底要按各臂自己的量级重算**（读数的最小刻度在 0.015 ms 量级上自己就占 6.7%，拿老师的百分比套学生=假过闸）；**拟合式不许跨架构外推**，要在训练前把它写成可打的数字当预测（ml-compress 第4课：0/6 命中、误差 −83%~−85%，那条"上界"属于那副图不属于机器）；**"再跑一遍"不等于复现**——固定种子下重跑逐位复现，量不到种子方差，误差棒必须由真正产生它的那个随机源给（换随机流 / 换机器状态 / 换进程是三种不同的方差。ml-compress 第4课b：换 3 条随机流重训后，满数据"蒸馏有害"扛住了、低数据那点好处被降级）；**拟合出来的"物理上限"报成带、不报成点**（同配置跑到 5 次，固定开销的跨度从 5.3pp **涨**到 5.8pp——带宽是当轮机器状态传导进截距的，加样本量救不了；跨运行真正稳的只有同轮比率，极差 2.8%）；**对照臂的统计量要先证明不退化**（ml-compress 第4课c：配平臂每个温度只有一个 α，"跨 α 极差"按构造恒为 0，第一版于是打印出"配平后 T 轴被压平 ⇒ 原假说借温度复活"这个反向结论，改成"钉回梯度换回多少伤害、与种子底比"才拿到正确判决——能算出 0 的差值不等于没有差；顺带一条：零训练探针推翻实验自身前提（α 与 T 并不正交）时，正确动作是照它改设计，不是沿用旧假说的措辞收尾）；**加参数开关必须档案驱动**（ml-compress 第4课c 加 `--width 64`：锚点档案值、H1 的伤害基数、种子底三样全部从该宽度自己的 `compress_report_v4b*.json` 读，并加 `width` 字段闸门，拿错档案就直接报错退出而不是回落到默认字面量——多写一套字面量就等于多装一个会悄悄说谎的对账栏，逐位对账闸门一绿人就停止怀疑了）；**跨架构迁移 ≠ 独立复证**（换宽度重扫测的是"这条结论绑不绑架构"，两副学生仍共享同一个老师、同一批数据、同一份软标签，数据那侧的独立性要换 teacher 才拿得到；所以判词要写在自己的适用范围内："在这台机器上、这一副学生上"，而不是一句"蒸馏无用"；**这笔债第5课已还**：换 teacher 重扫后低数据那条正号照旧，"跨架构 ≠ 独立复证"于是从告警变成已排除的一项）；**借来的底会埋效应，自己的 ±2SE 会造效应**（ml-compress 第4课d：种子底从别处借来用，对单格普遍偏大（最松的自有闸门只有它的 0.12x），于是压住 5 个真小效应；换成本格配对极差推的 ±2SE，三种子跨格共用同一批随机流 ⇒ 独立合成是**下界**，又会把噪声抬成"翻档"。两个方向的错**都不是靠换尺子解决**——用尺子挑出该补样本的格子，然后加种子，别改判据）；**同一把尺子只对不利读数严格，等于没有尺子**（ml-compress 第4课e：板块历史上 n=3 的正号已经死过两次，所以低数据档那条**有利**的 +71.7 张也走同一遍 n=8 补种子——结果一条正号被自己杀掉（CI 跨 0），另一条活成板块第一条 H+；对自己有利的读数，判据一个字都不许松）；**符号也是杠杆的一部分**（ml-compress 第4课c/第5课：同一个 T=6 在 8500 张档是全表最差、在 2000 张档是全表最优，所以"该拧哪个旋钮"的答案必须写清"这一版模型训练时看到多少数据"；连带一条工程约束——**符号会翻的表，读法和判词里不能把符号写死**，第4课c 第一版把"伤害主要住在哪一步"和 `min(...)` 一起硬编码，换到低数据档就打印出方向相反的话，改成按该档实测符号分支取 `max/min` 才闭嘴）；**"复现了哪一维随机源"要跟着结论一起报**（ml-compress 第5课：换种子、换宽度、换机器状态、换老师是四种不同的独立性；造第二副老师时先量它到底换了多少（10000 张里 94 张判得不一致、软标签 KL 0.0112），并把"不吃该变量的那一臂"（CE 锚 6/6 逐位对账）当准入条件——**先证明没变的部分没变，才敢谈变了的部分**）；**先问伤害是剂量型还是污染型，再决定要不要降剂量**（ml-compress 第4课f：把 α 阶梯铺到锚点剂量的 7%，拿到的却是锚点伤害的 79%——曲线第一个读数之后就饱和 ⇒ "少掺点就安全"这条路按构造不存在，此时该改的是目标分布不是权重；顺序反了会一路把剂量降到零还在等一个不会来的拐点，而 α=0 那一格**必须逐位等于 CE**，这条接线闸顺手把"我是不是把 loss 接错了"排除掉）；**已入库的档案要拒绝重跑**（ml-compress 第5课：同一把刀重跑会无声盖掉上一版的判决，而盖掉之后没有任何东西能证明曾经有过不同版本——落盘产物比口头结论强的唯一一点就是它能被打脸，所以要挡住被覆盖；闸门在第一次训练之前就退出，不是跑完再提醒）；**n=3 的同向叫支持，不叫裁决**（ml-compress 第5课 第三副老师：三副软标签"越干→满数据之害越大"3/3 同向，这条新读数是本轮唯一超出复现的东西，但它们出自同一族剪枝刀的不同剂量，干湿与剪枝剂量、老师精度三者同向变化，分不开 ⇒ 判词必须带这句限制）；**支持性排序要用"换一族旋钮"去判，不能用同一族的第 N 个重复**（ml-compress 第5课 第四副老师：三点排出的"软标签越干→伤害越大"看着漂亮，但它全部出自同一把剪枝刀的不同剂量——换个剂量只是再加一个相关点。真正判掉它的是换一族旋钮：同一副网络、同一批图、同一段配方只把 20 epoch 砍到 3，软标签湿 46.2pp，结果最湿的老师打出的伤害比最干的还大 ⇒ **一条排序如果是共变的别名，换掉自变量它就断**；断掉的判词只删掉错的那半句，"符号跟数据量"那半句照旧）；**尺子要量对它测的那个随机源**（ml-compress 第4课e 第三发：低数据 T=3 两格 n=8 均值 +31.8/+29.8 张都在"借来的种子底 37 张"以下却判 H+，不是自相矛盾——种子底量的是**单臂重训一次错图数漂多远**，而 gap 是**同起点同批次的配对差**，它自己的 σ 只有 16~17 张；拿单臂的尺闸配对差，等于用体温计量血压。前几课用借来的底是因为 n=3 估不出配对差的 σ，那是**不得已的代理**不是正确仪器）；**夹紧实验会失败，失败要报成"没量到"**（ml-compress 第4课g：想给"符号翻在 2000~4500 之间"补三个中点，结果三档读数全在本档自己的底以内（0/3 过闸）——既没钉死斜坡也没钉死台阶。诚实写法是把那句话的支撑改回"只站在两个端点上"并顺手披露端点当年用的是更小的借来的底，而不是把 +0.5/−16.1/−15.2 描成"趋势"）；**真独立复证的产出常常是分半的，而且效应大小必须连着该任务的底一起报**（ml-compress 第6课 FashionMNIST：换任务是五种独立性里唯一动到"世界"的那一维，结果一半复现一半没有——满数据那一刀 −125.5 vs MNIST −130.2 张几乎原样，低数据那个翻号没复现（−94.7 张，在本档底 106 以内＝测不动，按预立判据**不许**改口成"MNIST 特产"）；同时同一套仪器在 Fashion 上的底是 MNIST 的 2.6~2.9 倍，所以"多少张"这种报法跨任务就是吹牛）；**档案名要跟着判别变量走**（ml-compress 第4课e：换温度跑第二遍时脚本档案名只跟数据档不跟温度，再跑一次会**无声盖掉**上一轮的判决——落盘产物比口头强的唯一一点是它能被下一轮打脸，被覆盖连"曾经有过不同版本"的证据都不留；"已入库拒绝重跑"的闸门必须建在真正的判别维度上）；**"测不动"是一句关于尺子的话，不是关于世界的话**（ml-compress 第6课续：同一档数据、同一批图，n=3 用单臂底判"测不动"，n=8 用配对 CI 判"有方向"（−79.1 张、8/8 同号）——改的是尺子；所以报"测不动"必须同时报"用的是哪把尺子"，而改口时要写清这笔债是**上一课自己记下的**，不是事后挑出来的口径）；**独立性要按买到的那一维报，别把分辨率当复证卖**（ml-compress 本轮四发：两发 n=8 买的是分辨率、换不相交样本买的是样本批次、任务内换老师买的是知识源，只有换任务动到"世界"——同一次实验里这几笔要分开记）；**想判一个假说，先把闸门装硬到能红**（ml-compress 第6课b：任务内换干湿那一发开跑前先要求"干湿真的动了 ≥10pp"（实测 +21.5pp），否则这一发**没有判别量**、直接退出；而 CE 锚对账那条闸用 `--red-check` 故意拿错基准跑成红的才算装好——没有这两件闸，−84.9 张只能读成"干湿无效"，而它完全可能是"干湿没被换过"）；**连"形状判词"都不是定律**（ml-compress 第4课f 补两发：α→0 阶梯在 MNIST 三个坐标上都判"污染型"（第一个读数吃掉 63%~97% 的锚点伤害；**这三处后来都补到 8 条流，同一批坐标重读是 62%~118%**——越界那一档见下面"派生比值有定义域"那一条），换到 Fashion 满数据档判成"有阈值"；搬结论时要连形状一起重测，而且负读数要先证明仪器看得见这个量级（那批发里与 CE 不同 249~762 张））；**要拆混淆，就把那一维搬进同一个任务里做配对差**（ml-compress 第7课："符号跟数据量还是跟这份软标签"吵了几轮，是因为每次换任务都顺手换了软标签；把两副老师放进同一任务、同一批 8 条流、同一顺序，差值才有以流为单位的 CI（−72.3 张 [−100.0,−44.7]）。跨任务的两条序列哪怕各自 8/8 同号，相减也没有配对意义——只并列，不检验）；**形状判词要报它站在哪一列温度上，正号要报它是几条流读出来的**（ml-compress 第4课f 第五、六发："有阈值"只在 T=6 那列量过就得写上边界；搬到 T=1 那一列时 3 条流的 +44.7 张缩成 8 条流的 +17.1 张、流级只剩 5/8，而形状判据用的是逐图合并检验 ⇒ 标签照打"有阈值"，那一列其实两说都没判。**对判据不满意要在开跑前预登记再重跑，不能看到读数之后换尺子**）；**分母随 n 机械变长的比值，不许跨账互相比**（ml-compress 第4课b/c 补 8 条流：同一格同一批图，只把流数从 3 升到 8，"疗效 ÷ 种子底"就从 1.76x 掉到 0.86x——因为底是 max−min 型统计量，它在 E[极差]=D4(n)·σ 下只涨不跌。同一件事在配对 CI 那一侧不发生（−66.1 张 CI [−82.2,−50.0] 与 3 条流时同向同量级）。所以补流那一发的判词必须写"用的是哪把尺子"，而"补流之后原来的结论被推翻了"这种话八成是分母涨了不是效应没了；**还有一条免费的硬闸：扩流的那本必须与老那本在共有流上逐位相同，否则新读数是换了一把尺子而不是把同一把尺子量得更精**；**验红脚本自己也要能被拆红，拆不动的那一条要报成灵敏度**（ml-compress 第4课f v3：六道闸配自红模式——那一轮五个、四个如期红，本轮补到七个、六个如期红），`--destroy`（把"全部流同号"放宽成"最多一条反例"）**在现有读数上照样绿**——因为那几本的流级同号本来就是满的，这条腿此刻不承重。正确写法是"这条闸在当前这批读数上不承重，所以它没红是一次测量而不是一次通过"，而不是删掉那个模式或者把绿当成绩。同一规矩早就管着训练脚本的闸（`--red-check`、空表恒真不算测过），现在管到判据的守卫脚本本身）；**守卫挑基准账的规则本身也是被测对象，出了假案要修规则、不许豁免字段**（ml-compress 本轮：闸⑤ 用 glob 顺序最老那本当"重跑本的前一版"，于是把"v1→v2 时判据合法新增的派生字段"读成"训练路径漂了"——红是红对了方向，红错了对象。豁免那个字段就等于给下一次真漂移留一扇门，所以改的是挑选规则（基准＝同流同配置里版本号最高的前一版），并给两种错法各留一档永久突变模式：`--sibdrift` 偷偷 +7 一个训练路径数（实测点名 3 本、退出码 1）、`--oldsib` 故意挑最老那本（实测红 1 次、退出码 1）。**一条规矩的两种错法都要能被钉住，才算这条规矩有牙齿**）；**派生比值有定义域，出界时该改口的是那句话而不是那个数**（ml-compress 本轮：中数据档补到 8 条流后"买到锚点伤害的 97%"变成 **118%**。分子是本发现读、分母是"顶格有多伤"，而顶格自己也是带噪声的读数——它从 −47.3 掉到 −38.5 就把比值推过界。118% 不是更准的份额，是"份额"这个词失效的信号（此时真正该说的是"最小剂量比顶还伤"＝倒挂），而判据的分支表里没有这一支、它被"污染型"顺手吞掉。动作顺序照旧：**先在已入库档案上离线验红、再预登记新分支**；同一条纪律管文档：写死"x%"的句式要先问它 x 的取值范围）；**改口要付费：一个新分支必须交齐"预言→闸→同流活重跑"三段**（ml-compress 第4课f v4：上一轮记下的"份额话出界"本轮真的做成了分支——先离线预登记"只有那一本该改口、界内两本一个字不许动"，再用闸⑦ 证明翻转集合**恰好等于**预言（多翻一本=连坐，一本不翻=装饰），最后拿同一批 8 条流活重跑一遍：**14 个训练路径字段逐位不动、只有判词从"污染型"改口"污染型·倒挂"**。付费的意思是这一串要在读数之前就写好，而不是跑完再补——补出来的叫解释，不叫验证。同一条纪律还留下一笔明账：那句"最小剂量比顶还伤"的**配对步长 CI 跨 0**（+7.1 张 [−3.4,+17.6]、6/8），所以判词可以打"倒挂"，但"这一步测干净了"不能说）；**加一条判决腿就要配一道只盯它的闸，旧闸结构上看不见新腿**（ml-compress 第4课f v4：闸④ 定义在 v2/v3 的复算上，所以 `--v4loose`（把倒挂腿放松成"判到污染型就改口"）在它眼皮底下**照样绿**——不是④松，是它管不到这条腿。真正抓到它的是新加的闸⑦（翻转集合必须等于预登记）。同理 `--v4blind`（v4 直接瞎掉倒挂腿）也只红 ⑦；**一条闸的适用范围要写进它的名字里，否则"全绿"会被读成"什么都测到了"**）；**指不到盘上文件的"已经跑过"一律作废**（ml-compress 本轮：文档里记着"已通过"的那段运行输出，对应的源码在盘上有一行未闭合的 f-string——**SyntaxError，那次运行不可能来自这个工作树**。所以凡是引用一次运行的结论，要么给出能复算它的档案文件名，要么给出能跑通它的源码行号；两者都给不出，就当它没跑过、重跑。加一条：**守卫文档里写死的"实测红几条"也只对当时在册的那几本成立**，本轮档案 14→15 本，`--decorative` 从 5 条红涨到 7、`--misfeed` 从 14 涨到 19——沿用上轮的数字=那张表已经在说谎，改成"加一本账就重跑全部突变模式再写回"）
