# ml-toolcall — 30M 小模型函数调用：一门以负结果为产出的课

> 实验全程发生在 [minimind](https://github.com/jingyaogong/minimind) 仓库的本地工作副本（30M 参数、hidden 512 的自训小模型），本板块是它的**教学蒸馏**：一条实验线怎么被四个负结果钉死天花板、每个负结果怎么从"失败了"升级成"可复现的结论"。原始日志与脚本以 minimind 目录为准（本文全部给出路径），一手记录在 `minimind/EXPERIMENTS-toolcall.md`。

任务长这样：给模型 8 个 mock 工具（计算器/天气/汇率/单位换算/随机数/时间/翻译/文本长度），用户说一句"帮我算 256×37"，模型要输出结构化的调用声明（工具名 + 参数 JSON），由本地代码真实执行。这是所有 Agent 框架的地基能力。

**先亮结果：这条线以止损结案。** 数据侧四条修法（强化学习、契约提示词、扩容 2.3 倍、对抗样本 19%）全部被证伪，天花板定性为**预训练+RLHF 给的能力先验缺口，不是工程缺陷**。下面六课，每一课都是"提出假设 → 设计能杀掉假设的实验 → 挨打或验尸"。

## 为什么值得花三天学负结果

第 9 课（ml-text 收官之十）里 LLM API 裸考 0.913 碾压我们调了七课的 TF-IDF——那一课打掉的是"传统 ML 行不行"；这条线打掉的是"自己训小模型行不行"。两次加起来才是完整的世界观：**你的两次直觉（换方法、自己练）都被同一个变量杀死——训练时烧进去的先验**。而"什么时候该停"只能靠显著性检验回答，这条线就是这个回答过程的完整标本。

## 第1课 RL 死路：探索要先摸得到奖励

CISPO 训 174 步，reward 全程为负，模型一次都没"碰巧"生成过合法的调用标签。**为什么**：策略梯度靠"试出好的再强化"，而 30M 模型在没有任何格式先验时，生成合法结构化标签的概率低到探索空间里根本采样不到——没有正样本可强化，梯度指向虚无。1.8B 的 reward 模型都救不了它，因为问题不在判卷在答卷。

**可迁移的判据**：RL 适合"你已经偶尔会做对，要做得更稳"；不适合"从零无中生有"。格式类任务先 SFT 给先验、再谈 RL——顺序反了就是烧钱。

## 第2课 合成 SFT：一条设计值回全部学费

"LLM 只出题、执行在本地"：让 qwen-plus 只生成「用户请求 + 调什么工具 + 参数是什么」，8 个 mock 工具**真实执行**产出返回值，最终答复用每工具的答案模板拼装——LLM 从头到尾没编造过一个数字，从源头掐掉幻觉样本。参数不合法/执行报错的样本本地校验直接丢。

首轮 539 条有效数据就把格式教成（8/8），证明**格式可以很便宜，选型才是贵的**——这个"便宜/贵"的切分是后面四课的实验设计基础。

**事故（本课真正的学费）**：合成脚本原来只在最后一次性落盘，进程静默死 21 小时 → 一天的付费 API 全丢。修复成逐批检查点（`dataset/_synth_cache/*.jsonl`，成品写出后自动清理）+ 瞬时 API 失败跳过重试。**任何要跑几小时的批处理，落盘粒度就是你能承受的失败粒度。**

## 第3课 契约增强：一次完整的"效应不存在"结案流程

把工具 description 从一行短描述升级为 WHEN TO USE / NOT USE / 边界 / 互斥的契约文案（业界普遍相信这样能减少误调用）。评估协议 `ab_toolcall.py`：同模型、同 8 题、固定种子流 ×3 重复（n=24/臂）、近贪心解码、配对符号检验。

| 轮 | 模型 | 短描述 | 契约 | 配对（短胜:契胜） | 当时误判 |
|---|---|---|---|---|---|
| round1 | 首轮 SFT | 18/24 | 12/24 | 3:1 | "pooled p≈0.07，契约有害！" |
| round3-cont | 续训退化版 | 15/24 | 15/24 | 3:3 | — |
| round3-clean | 双判据过滤重训 | 12/24 | 9/24 | 6:3 | — |
| **合并** | | | | **9:6** | **p≈0.61，结案：既无害也无益** |

三个方法论节点：① round1 的"疑似有害"是 n=24 噪声——**方向可疑时第一反应是加样本，不是写结论**；② 三轮的臂间比对做过机制自审（两臂 first_call 逐条比对 15/24 同，确认提示词没有渗进对方的臂）；③ 结案语是"在 30M 上无效应"，不是"契约没用"——**结论的适用范围必须等于实验的适用范围**。

## 第4课 扩容反噬：揪出"第二类坏样本"

539→1219 条（合成 1600 过滤）重训，冒烟直接崩成复读机（输出 `"calculate_unit":` 无限重复）。逐层排查的教科书流程：

1. **对照重训**排除"续训改坏了"：从干净基座重训，仍崩 → 锅在数据。
2. **审计数据**抓到凶手：训练器的 `generate_labels` 只学 assistant 段、序列渲染超 1024 时**最末收束标记被切掉**——这类样本 label 非零（骗过第一版过滤器），训练等于教模型"话说到一半不许停"。本批 1219 条里 70 条中招。过滤器升级为双判据（零信号 + 尾截无收束）。
3. **修完数据重训，选型仍退化**（18/24→12/24）。串台模式（weather 吃 unit 的参数）不在训练数据里——是 30M 的泛化失败，扩量稀释了正确模式却没补上先验。

**可迁移判据**：截断不是中性的清洗操作，它会把"停止信号"从监督里拿掉。任何有 max_length 的 SFT，先数一遍有多少样本的收束标记被切——`filter_zero_signal.py` 双判据可以直接抄。

## 第5课 对抗样本：最干净的一次"逐字同分"

针对串台开药方：`make_toolcall_keys.py` 生成"参数键对照"样本——题面必须沾其他工具的参数词（诱饵），正确调用只用本工具的 schema 键，且经真实 mock 执行校验。存活 269 条并入底座 = 1390 条，对照占比 19.4%。重训后 A/B：**before 12/24、after 9/24——与第4课无对照版逐字同分、同失败点**（unit/random 输出 None、汇率→时间、weather→unit_converter）。

这次"同分"有两层含义：① 药方无效——19% 的对抗样本修不动泛化失败；② **仪器可信**——两份不同数据集训出的模型在同一评估上分数一字不差，说明近贪心协议测的是能力本体而不是噪声。负面结果的可信度来自复现，这次复现是白送的。

## 第6课 规模对照线：给"天花板"换个坐标系

到此还剩一个反驳：会不会是你的评估协议对自训模型太狠？拿同 8 题、同两臂文案、同解码参数去跑 Ollama 原生模型（判分用 /api/chat 结构化 tool_calls）：

| 模型 | 训练量 | HEAD 短描述 | 契约增强 |
|---|---|---|---|
| 30M（本线自训） | 合成 1390 条 SFT | 12/24 | 9/24 |
| qwen3:0.6b | 预训练+后训练 | 21/24 | 21/24 |
| qwen3.5-4b | 预训练+后训练 | 24/24 | 24/24 |

三个读数：① 同题同尺，0.6B 拿下 7 倍于 30M 的成绩——缺的是**先验**不是题目；② 失败模式发生**相变**：0.6b 唯一失分是"现在几点了？"三 rep 全部直接作答不调工具——从"选错"变成"不愿调"，这是两种不同的病；③ 契约在能测出它的规模区间（0.6b 两臂 21:21 同分同死穴）从未转正，4b 双双饱和——第3课的结案没有翻案空间。**饱和时换尺子**（这条纪律来自 ml-rag，在这里救了一次"0.6b 和 4b 谁强"的无效对比——4b 24/24 什么也证明不了，得回到 0.6b 那行读数）。

## 总账：一张止损决策表

| 想修的 | 修法 | 代价 | 结果 |
|---|---|---|---|
| 格式不会 | RL 直接教 | 174 步 GPU | 死路 |
| 格式不会 | SFT 合成数据 | ~539 条，一次 API 长跑 | **成了**（唯一正向） |
| 选型差 | 契约提示词 | 三轮 A/B，n=72/臂 | 无效应 p≈0.61 |
| 选型差 | 数据 ×2.3 | 重训 + 一场复读机事故 | 退化 18→12 |
| 串台 | 对抗样本 19.4% | 重训 + A/B | 逐字同分 |
| 以上全修不动？ | 规模对照线 | 零训练（纯推理 API 调用） | 天花板=先验，**止损成立** |

**再碰这个题的正确姿势**：换 ≥100M 基座或换真预训练语料，别在 30M + 合成 SFT 的配方上继续绣花。

## 操作纪律（两轮事故换来，全项目通用）

1. 长跑批处理**逐批落盘**（第2课事故：21 小时静默死亡，全天 API 费归零）。
2. **改权重前先 cp 备份**（round1 的 8/8 权重被续训覆盖，导致第4课缺最干净的对照）。
3. max_length 截断是标注问题不是清洗问题：**数一遍被切收束标记的样本**。
4. 结论出口前问一句：适用范围写清了没有？（"契约对 30M 无效应" ≠ "契约没用"）
