## 三、三句口径（被追问时先交这三句）

- **单位**：效应一律报"多少张 + 该档自己的底倍数"，不报 pp——同一套仪器在 Fashion 上的种子底是 MNIST 的 2.6~2.9 倍。
- **独立性有六种**：换种子 / 换宽度 / 换老师 / 换任务 / 换样本批次 / 换机器状态。n=8 那批发买的是**分辨率**，不是独立性；账要按买到的那一维报。
- **闸门先于读数**：α=0 恒等闸、CE 锚逐位对账、"干湿必须真的动"、`--red-check` 把闸跑成红的、"空表全过 = 没测到"。**判词要连着判据版本一起读**：同一批数字在 v1（只看逐图合并 p）下是"有阈值"、在 v2（再加"全部流同号"）下是"测不动"——所以档案名里带 `_v2`，两个标签并存而不是覆盖。

## 四、这张表欠的债（若被问"下一步"）

- α→0 阶梯只铺在三列温度上（MNIST T=3、Fashion T=6 与 T=1）；α>0.7 之上还涨不涨没测——Fashion 那本账没有更大的 α。
- **形状判据 v3 欠两件事**（本轮 v2 还掉一条腿，同时留下这两条）：① 判据只吃"最小剂量格 + 闸格"两格，**阶梯顶 α=0.7 那一格它没看**——低数据档那一本因此印"测不动"，而顶格其实 8/8 同号；② "两格反号"这种形状**不在预登记的三分支里**，只能靠现场解释，得给它一个正式分支。两者都只能预登记后重跑，不能拿本轮这本账改口。
- **v2 那条流级腿在 3 条流上只等于"无反例"**（n=3 全同号的精确二项 p=0.25，不到 0.05）。所以板块那三本"污染型"在 v2 下既没变严也没变松——**要让这条腿真有意义只能补流**（v4b/v4c/v4f 老档案扩到 8 条流），不能再换判据。
- v4b / v4c / v4f 那批老档案仍是 3 条流：跨种子极差还是粗估，只有被点名的格子扩到了 8 条。
- 第7课判的是"这一档有没有方向"，没判"该选哪个 α"：老师 D 那副的正号塌了，但没给出替代超参。
- 全部读数在 600 步小 CNN、两个数据集、四副老师、两副学生宽度上。换 transformer 或换真实部署后端，这张表没有一行可以直接搬。
