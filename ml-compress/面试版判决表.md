# ml-compress 面试版判决表（一页）

用法：左列是可以照着说的一句话，中列是它**只在哪些坐标下成立**，右列是**哪一发立的、哪一发动过它**。
搬用坐标外的话，就是这张表要防的那件事。读数全部出自同目录的 `compress_report_v*.json`，可现读复核。

## 二、被自己下一枪拆掉的（讲这些比讲结论值钱）

| 曾经说过的话 | 谁拆的 | 拆完剩下什么 |
|---|---|---|
| "KD 让精度涨了 0.15pp" | 第3课对照臂（同结构、不剪枝、同微调） | 那是噪声不是疗效 |
| "这格只有 0.24x 底 ⇒ 不算效应" | 第4课d：跨格 ±2SE 是**下界**，会把噪声合成成效应 | 它只当"值不值得补种子"的筛子，不当判决 |
| "T=1 的 KD 正效应"（MNIST 满数据档） | 第4课e：补到 8 条流后 CI 跨 0 | 3 条流的正号是刻度假象 |

## 三、三句口径（被追问时先交这三句）

- **单位**：效应一律报"多少张 + 该档自己的底倍数"，不报 pp——同一套仪器在 Fashion 上的种子底是 MNIST 的 2.6~2.9 倍。
- **独立性有七种**：换种子 / 换宽度 / 换老师 / 换任务 / 换样本批次 / 换机器状态 / **换温度列**（最后这一维本轮一次用了三回，见下面那三条 `_t6` 判决）。n=8 那批发买的是**分辨率**，不是独立性；本轮往中数据档再加四条流（n=12）买的**还是**分辨率——同一批图、同一个老师、同一个训练器，所以那一发**不许被写成"倒挂被复证了"**。账要按买到的那一维报；而"我登记了守卫会验这一条"和"那道闸真的看得见这一对"也是两件事——本轮为把它们分清，在 282 秒的训练之外又重跑了九档拆红。第三种买法本轮也出现了一次：`--ladder-high` 那发**既不买分辨率也不买独立性**，它买的是"没测过的坐标段"（α>0.7 那两格，仍在那 8 条流上）⇒ 账上多的是**覆盖**，判据吃的一个字没动。**代价也在这里现形**：那一发第一次真跑把 64 次训练全烧完之后才死于一个 `KeyError: 1.0`（`by_seed` 只装了判据吃的两格，新格不在里面），而我确实做了零训练预飞——预飞的是**守卫**，没覆盖**训练之后才执行到的那段打印**。修完之后固定动作变成：**先用 `--nseeds 3`（约 1 分钟）把整条路径走通，再开真跑**（预演账删掉不入库）。上一轮刚写下"最贵的失败要提前到花钱之前"，这一轮就用一次重跑把它补全成：**提前到"训练之后才跑到的那几行"之前。** 第四种买法本轮也**第一次落地**了：`step4h` 那一发**既不买分辨率、不买独立性、也不买覆盖**（没加流、没换那七维里任何一维、没长 α 格），它买的是**判别量**——同一批流上把"两个点估计相减"换成"逐流配对差"。这种账上多出来的是 **CI / 同号 / 二项 p**，所以它永远不许被写成"某句话被复证了"；反过来，它也不许被省掉：同一个点估计之差，配对了才知道它到底含不含 0（本轮两档就此分家：一档升格、一档差 0.4 张没升格）。
- **闸门先于读数**：α=0 恒等闸、CE 锚逐位对账、"干湿必须真的动"、`--red-check` 把闸跑成红的、"空表全过 = 没测到"。**判词要连着判据版本一起读**：同一批数字在 v1（只看逐图合并 p）下是"有阈值"、在 v2（再加"全部流同号"）下是"测不动"、在 v3（判据吃进阶梯顶＋反号有正式分支）下可以是"反号线"、在 v4（界内照旧说份额、出界改口倒挂）下可以是"污染型·倒挂"——所以档案名带 `_v2`/`_v3`/`_v4`，历代判词并排存在档案里（`verdict` + `verdict_under_v1_rule` + `verdict_under_v2_rule` + `verdict_under_v3_rule`），任何人都能零训练复算。**同一条规矩管验红脚本自己**：`_red_v3.py`
