## 跨项目方法论（踩出来的）

1. **泄漏是头号公敌**：时间泄漏/元数据泄漏/评估泄漏，每个项目用对照实验量化一次
2. **指标反常 = 流程警报**，先审计后庆祝（时序课因此发现多步预测标签泄漏）
3. **误差分析决定投资方向**：分片、混淆对、置信度分层收益 > 换模型
4. **train/serve 一致性**：一套预处理从训练用到线上（增强不对齐分布时是毒药，有实验）
5. **上线三件套**：置信度阈值 + 输入护栏 + 拒答转人工
6. **评估工具也是被测对象**：RAG 首轮输给裸考，查出的问题是提示词和判卷官自己；judge 全给满分是量表饱和，不是完美
7. **墙钟数字必须先量仪器自己的分辨率**：同一份权重测两遍当对照臂，噪声底压不住差异就不许下结论；"一臂跑完再跑下一臂"能漂 4.3 倍，同进程交错配对能压到 1.15 倍——坏的是估计算法，不是延迟这个指标。逐条追加（**这一串故意不数条数**：上一版写"六条追加"时底下已经挂着七条，连"几条"这种最该确定的数都会腐烂）：**底要按各臂自己的量级重算**（读数的最小刻度在 0.015 ms 量级上自己就占 6.7%，拿老师的百分比套学生=假过闸）；**拟合式不许跨架构外推**，要在训练前把它写成可打的数字当预测（ml-compress 第4课：0/6 命中、误差 −83%~−85%，那条"上界"属于那副图不属于机器）；**"再跑一遍"不等于复现**——固定种子下重跑逐位复现，量不到种子方差，误差棒必须由真正产生它的那个随机源给（换随机流 / 换机器状态 / 换进程是三种不同的方差。ml-compress 第4课b：换 3 条随机流重训后，满数据"蒸馏有害"扛住了、低数据那点好处被降级）；**拟合出来的"物理上限"报成带、不报成点**（同配置跑到 5 次，固定开销的跨度从 5.3pp **涨**到 5.8pp——带宽是当轮机器状态传导进截距的，加样本量救不了；跨运行真正稳的只有同轮比率，极差 2.8%）；**对照臂的统计量要先证明不退化**（ml-compress 第4课c：配平臂每个温度只有一个 α，"跨 α 极差"按构造恒为 0，第一版于是打印出"配平后 T 轴被压平 ⇒ 原假说借温度复活"这个反向结论，改成"钉回梯度换回多少伤害、与种子底比"才拿到正确判决——能算出 0 的差值不等于没有差；顺带一条：零训练探针推翻实验自身前提（α 与 T 并不正交）时，正确动作是照它改设计，不是沿用旧假说的措辞收尾）；**加参数开关必须档案驱动**（ml-compress 第4课c 加 `--width 64`：锚点档案值、H1 的伤害基数、种子底三样全部从该宽度自己的 `compress_report_v4b*.json` 读，并加 `width` 字段闸门，拿错档案就直接报错退出而不是回落到默认字面量——多写一套字面量就等于多装一个会悄悄说谎的对账栏，逐位对账闸门一绿人就停止怀疑了）；**跨架构迁移 ≠ 独立复证**（换宽度重扫测的是"这条结论绑不绑架构"，两副学生仍共享同一个老师、同一批数据、同一份软标签，数据那侧的独立性要换 teacher 才拿得到；所以判词要写在自己的适用范围内："在这台机器上、这一副学生上"，而不是一句"蒸馏无用"；**这笔债第5课已还**：换 teacher 重扫后低数据那条正号照旧，"跨架构 ≠ 独立复证"于是从告警变成已排除的一项）；**借来的底会埋效应，自己的 ±2SE 会造效应**（ml-compress 第4课d：种子底从别处借来用，对单格普遍偏大（最松的自有闸门只有它的 0.12x），于是压住 5 个真小效应；换成本格配对极差推的 ±2SE，三种子跨格共用同一批随机流 ⇒ 独立合成是**下界**，又会把噪声抬成"翻档"。两个方向的错**都不是靠换尺子解决**——用尺子挑出该补样本的格子，然后加种子，别改判据）；**同一把尺子只对不利读数严格，等于没有尺子**（ml-compress 第4课e：板块历史上 n=3 的正号已经死过两次，所以低数据档那条**有利**的 +71.7 张也走同一遍 n=8 补种子——结果一条正号被自己杀掉（CI 跨 0），另一条活成板块第一条 H+；对自己有利的读数，判据一个字都不许松）；**符号也是杠杆的一部分**（ml-compress 第4课c/第5课：同一个 T=6 在 8500 张档是全表最差、在 2000 张档是全表最优，所以"该拧哪个旋钮"的答案必须写清"这一版模型训练时看到多少数据"；连带一条工程约束——**符号会翻的表，读法和判词里不能把符号写死**，第4课c 第一版把"伤害主要住在哪一步"和 `min(...)` 一起硬编码，换到低数据档就打印出方向相反的话，改成按该档实测符号分支取 `max/min` 才闭嘴）；**"复现了哪一维随机源"要跟着结论一起报**（ml-compress 第5课：换种子、换宽度、换机器状态、换老师是四种不同的独立性；造第二副老师时先量它到底换了多少（10000 张里 94 张判得不一致、软标签 KL 0.0112），并把"不吃该变量的那一臂"（CE 锚 6/6 逐位对账）当准入条件——**先证明没变的部分没变，才敢谈变了的部分**）；**先问伤害是剂量型还是污染型，再决定要不要降剂量**（ml-compress 第4课f：把 α 阶梯铺到锚点剂量的 7%，拿到的却是锚点伤害的 79%——曲线第一个读数之后就饱和 ⇒ "少掺点就安全"这条路按构造不存在，此时该改的是目标分布不是权重；顺序反了会一路把剂量降到零还在等一个不会来的拐点，而 α=0 那一格**必须逐位等于 CE**，这条接线闸顺手把"我是不是把 loss 接错了"排除掉）；**已入库的档案要拒绝重跑**（ml-compress 第5课：同一把刀重跑会无声盖掉上一版的判决，而盖掉之后没有任何东西能证明曾经有过不同版本——落盘产物比口头结论强的唯一一点就是它能被打脸，所以要挡住被覆盖；闸门在第一次训练之前就退出，不是跑完再提醒）；**n=3 的同向叫支持，不叫裁决**（ml-compress 第5课 第三副老师：三副软标签"越干→满数据之害越大"3/3 同向，这条新读数是本轮唯一超出复现的东西，但它们出自同一族剪枝刀的不同剂量，干湿与剪枝剂量、老师精度三者同向变化，分不开 ⇒ 判词必须带这句限制）；**支持性排序要用"换一族旋钮"去判，不能用同一族的第 N 个重复**（ml-compress 第5课 第四副老师：三点排出的"软标签越干→伤害越大"看着漂亮，但它全部出自同一把剪枝刀的不同剂量——换个剂量只是再加一个相关点。真正判掉它的是换一族旋钮：同一副网络、同一批图、同一段配方只把 20 epoch 砍到 3，软标签湿 46.2pp，结果最湿的老师打出的伤害比最干的还大 ⇒ **一条排序如果是共变的别名，换掉自变量它就断**；断掉的判词只删掉错的那半句，"符号跟数据量"那半句照旧）；**尺子要量对它测的那个随机源**（ml-compress 第4课e 第三发：低数据 T=3 两格 n=8 均值 +31.8/+29.8 张都在"借来的种子底 37 张"以下却判 H+，不是自相矛盾——种子底量的是**单臂重训一次错图数漂多远**，而 gap 是**同起点同批次的配对差**，它自己的 σ 只有 16~17 张；拿单臂的尺闸配对差，等于用体温计量血压。前几课用借来的底是因为 n=3 估不出配对差的 σ，那是**不得已的代理**不是正确仪器）；**夹紧实验会失败，失败要报成"没量到"**（ml-compress 第4课g：想给"符号翻在 2000~4500 之间"补三个中点，结果三档读数全在本档自己的底以内（0/3 过闸）——既没钉死斜坡也没钉死台阶。诚实写法是把那句话的支撑改回"只站在两个端点上"并顺手披露端点当年用的是更小的借来的底，而不是把 +0.5/−16.1/−15.2 描成"趋势"）；**真独立复证的产出常常是分半的，而且效应大小必须连着该任务的底一起报**（ml-compress 第6课 FashionMNIST：换任务是五种独立性里唯一动到"世界"的那一维，结果一半复现一半没有——满数据那一刀 −125.5 vs MNIST −130.2 张几乎原样，低数据那个翻号没复现（−94.7 张，在本档底 106 以内＝测不动，按预立判据**不许**改口成"MNIST 特产"）；同时同一套仪器在 Fashion 上的底是 MNIST 的 2.6~2.9 倍，所以"多少张"这种报法跨任务就是吹牛）；**档案名要跟着判别变量走**（ml-compress 第4课e：换温度跑第二遍时脚本档案名只跟数据档不跟温度，再跑一次会**无声盖掉**上一轮的判决——落盘产物比口头强的唯一一点是它能被下一轮打脸，被覆盖连"曾经有过不同版本"的证据都不留；"已入库拒绝重跑"的闸门必须建在真正的判别维度上）
