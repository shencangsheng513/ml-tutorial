# ml-compress 面试版判决表（一页）

用法：左列是可以照着说的一句话，中列是它**只在哪些坐标下成立**，右列是**哪一发立的、哪一发动过它**。
搬用坐标外的话，就是这张表要防的那件事。读数全部出自同目录的 `compress_report_v*.json`，可现读复核。

## 二、被自己下一枪拆掉的（讲这些比讲结论值钱）

| 曾经说过的话 | 谁拆的 | 拆完剩下什么 |
|---|---|---|
| "KD 让精度涨了 0.15pp" | 第3课对照臂（同结构、不剪枝、同微调） | 那是噪声不是疗效 |
| "这格只有 0.24x 底 ⇒ 不算效应" | 第4课d：跨格 ±2SE 是**下界**，会把噪声合成成效应 | 它只当"值不值得补种子"的筛子，不当判决 |
| "T=1 的 KD 正效应"（MNIST 满数据档） | 第4课e：补到 8 条流后 CI 跨 0 | 3 条流的正号是刻度假象 |
| 同上，Fashion 那一列（档案读数 α=0.7/T=1 = +44.7 张） | 本轮把 T=1 列搬到 8 条流：锚点缩成 **+17.1 张**、流级同号只有 5/8（二项 p=0.73）、配对步长 CI [−35.0, +71.8] 跨 0 | 这一列**两说都没判决**；逐图 p=0.03 撑不住流级 5/8，别拿前者讲后者 |
| 同一格上脚本自己印出的标签"**有阈值**（H1 半活）" | 本轮预登记的 v2 判据：一格算有方向必须**逐图合并 p<0.05 且全部流同号**。判据先对六本已入库档案离线验红（v1 复算 6/6 等于档案判词、v2 只翻这一本），再重跑那一发 | 标签正式撤成"**测不动**"，而 gap / 配对步长 / 两条闸 / arms 与旧档案**逐位相同** ⇒ 改口的只有判决，训练路径没被碰。**教训：合并 p 数的是同一批图上的翻牌，而 8 条流共用那批图——它只证明流内稳，不证明换个随机源还稳** |
| "α→0 阶梯的形状（污染型 / 有阈值）至少在同任务的三档数据上是稳定的" | 把同一条阶梯搬到最低那一档（MNIST 2000 张 / T=3 / 8 条流）：α=0.05 = **−18.9 张**（逐图 p=1e-06、7/8）与 α=0.7 = **+29.8 张**（8/8）**反号**，配对步长 +48.6 张 CI [+33.6,+63.6] | 形状判词**不跨数据量**：这一档既不是污染型也不是有阈值——预登记的 v3 判据（吃进阶梯顶、给反号一个正式分支）把它判成**反号线**：一条**带负截距的上升线**（先吞一点软标签、剂量到 0.3 以上才翻成收益）。同流重跑那本已逐位证明 gap/两条闸/arms 全不变，改的只有判词 |
| "符号由数据量决定"（当成任务级规律） | 第7课：同档换更湿的老师 D，+60.4 → −11.9 张；两副老师之差**按种子配对** = −72.3 张 CI [−100.0, −44.7]、8/8 | 降级成"数据量 × 这份软标签"的**交互**，且只在 MNIST 内部成立 |
| "伤害幅度跟软标签干湿走" | 第5课第四副老师 D（干湿↔幅度排序断了）+ 第6课b（Fashion 内部把老师训干 21.5pp，CI 上界仍 < 0） | 干湿既管不了幅度也管不了符号，能留下的只有"满数据那一刀很稳" |
| "翻号点在 2000~4500 之间，是斜坡还是台阶能判" | 第4课g：中点三档 × 两批**不相交**的图，0/6 过各自底 | 只站在两个端点上，而端点当年用的是更小的借来的底（37/20 张） |
| "反号线大概不止一个坐标"（上一轮记下的心愿） | 本轮把 v3 重跑本补到 Fashion 的 T=1 那一列（`--dataset fashion --nseeds 8 --thin --t 1`）：α=0.05 = **−1.2 张**（4/8、合并 p=0.76）、α=0.7 = **+17.1 张**（5/8、逐图 p=0.030 但流级 p=0.73）、配对步长 +18.4 张 CI [−35.0, +71.8] | **判"测不动"，与开跑前的离线预登记逐字一致**（那一格阶梯顶＝闸格 ⇒ v3 退化成 v2，多买的"吃阶梯顶"什么都没买到）⇒ **反号线至今只有 MNIST 低数据 / T=3 这一个坐标**。附带产出：这一发让守卫的闸⑤ **当场红**——它拿 glob 顺序最老的兄弟账当基准，把 v1→v2 判据自己换过的派生字段（`same_dir_seeds` 2/8→4/8）报成"训练路径动了"。修的是**挑选规则**（基准＝同流同配置里版本号最高的前一版），**没有豁免那个字段**，并留 `--sibdrift`/`--oldsib` 两档各钉住闸⑤ 的一端 |

## 三、三句口径（被追问时先交这三句）

- **单位**：效应一律报"多少张 + 该档自己的底倍数"，不报 pp——同一套仪器在 Fashion 上的种子底是 MNIST 的 2.6~2.9 倍。
- **独立性有六种**：换种子 / 换宽度 / 换老师 / 换任务 / 换样本批次 / 换机器状态。n=8 那批发买的是**分辨率**，不是独立性；账要按买到的那一维报。
- **闸门先于读数**：α=0 恒等闸、CE 锚逐位对账、"干湿必须真的动"、`--red-check` 把闸跑成红的、"空表全过 = 没测到"。**判词要连着判据版本一起读**：同一批数字在 v1（只看逐图合并 p）下是"有阈值"、在 v2（再加"全部流同号"）下是"测不动"、在 v3（判据吃进阶梯顶＋反号有正式分支）下可以是"反号线"——所以档案名带 `_v2`/`_v3`，三版判词并排存在档案里（`verdict` + `verdict_under_v1_rule` + `verdict_under_v2_rule`），任何人都能零训练复算。**同一条规矩管验红脚本自己**：`_red_v3.py` 七个拆红模式里六个如期红、`--destroy` 不红，那一条记成"这批读数不靠最后一条流"的敏感性测量，**不读成通过**。新增的两档各钉住闸⑤ 的一端：`--sibdrift` 偷偷改重跑本训练路径上的一个数 → 红；`--oldsib` 把基准兄弟账挑成最老那本 → 红。**能被拆红的才叫闸**。

## 四、这张表欠的债（若被问"下一步"）

- α→0 阶梯只铺在三列温度上（MNIST T=3、Fashion T=6 与 T=1）；α>0.7 之上还涨不涨没测——Fashion 那本账没有更大的 α。
- **形状判据 v3 已交付**（吃阶梯顶 + 反号正式分支，预登记后同流重跑）；它换来的只有一句"低数据档那一列是反号线"，**而反号线至今只有一个坐标**：本轮把 v3 重跑本补到 Fashion 的 T=1 那一列，判**测不动**（α=0.05 −1.2 张 4/8、α=0.7 +17.1 张 5/8、步长 CI 跨 0），与开跑前的离线预登记逐字一致 ⇒ 那是**一次否证**，不是第二个坐标，所以反号线目前是一个分支而不是一条规律。此外那本的阶梯顶就是锚点剂量本身，"再往上加剂量还涨不涨"仍未测（α>0.7 那一段没有档案）。
- **流级那条腿已经在 8 条流上有了牙齿**（v4b 两档、v4c 满数据九格、v4f 满数据非薄与低数据薄阶梯 = 12 格逐位对过）；**上一轮记下的两笔"只做过 3 条流"的欠账本轮都还了**：S64 那副宽度、中数据 4500 档各自补到 8 条流，判决一字未动，闸⑥ 的许可证从 1 对涨到 **3 对**（`v4f.json` / `v4f_s64.json` / `v4f_mid.json` 三本 3 流账各 12 格，都在对应的 `_n8_v3` 本里逐位重现）⇒ "跨流数只准读配对 CI"这条规矩现在有三个坐标撑着。
- **"买到锚点伤害的 x%" 这句话有定义域**：中数据档补到 8 条流后 x 从 97% 涨到 **118%**（分母那侧的阶梯顶从 −47.3 掉到 −38.5、只剩 7/8 同号），比值越过 100% 之后"份额"这个词就自我否定了。**欠一发 v4**：判据需要一个正式的"倒挂"分支（x>100 时改读"最小剂量比顶还伤"），且要像 v2/v3 那样先在已入库档案上离线验红再预登记。
- 还剩下的"只有 3 条流"：**第4课g 的中点三档**（2500 / 3000 / 3500，另加两批不相交的图）只做过 3 条流，"翻号点是不是斜坡"仍然悬着。
- 第7课判的是"这一档有没有方向"，没判"该选哪个 α"：老师 D 那副的正号塌了，但没给出替代超参。
- 全部读数在 600 步小 CNN、两个数据集、四副老师、两副学生宽度上。换 transformer 或换真实部署后端，这张表没有一行可以直接搬。
