## 跨项目方法论（踩出来的）

1. **泄漏是头号公敌**：时间泄漏/元数据泄漏/评估泄漏，每个项目用对照实验量化一次
2. **指标反常 = 流程警报**，先审计后庆祝（时序课因此发现多步预测标签泄漏）
3. **误差分析决定投资方向**：分片、混淆对、置信度分层收益 > 换模型
4. **train/serve 一致性**：一套预处理从训练用到线上（增强不对齐分布时是毒药，有实验）
5. **上线三件套**：置信度阈值 + 输入护栏 + 拒答转人工
6. **评估工具也是被测对象**：RAG 首轮输给裸考，查出的问题是提示词和判卷官自己；judge 全给满分是量表饱和，不是完美
7. **墙钟数字必须先量仪器自己的分辨率**：同一份权重测两遍当对照臂，噪声底压不住差异就不许下结论；"一臂跑完再跑下一臂"能漂 4.3 倍，同进程交错配对能压到 1.15 倍——坏的是估计算法，不是延迟这个指标。逐条追加（**这一串故意不数条数**：上一版写"六条追加"时底下已经挂着七条，连"几条"这种最该确定的数都会腐烂）：**底要按各臂自己的量级重算**（读数的最小刻度在 0.015 ms 量级上自己就占 6.7%，拿老师的百分比套学生=假过闸）；**拟合式不许跨架构外推**，要在训练前把它写成可打的数字当预测（ml-compress 第4课：0/6 命中、误差 −83%~−85%，那条"上界"属于那副图不属于机器）；**"再跑一遍"不等于复现**——固定种子下重跑逐位复现，量不到种子方差，误差棒必须由真正产生它的那个随机源给（换随机流 / 换机器状态 / 换进程是三种不同的方差。ml-compress 第4课b：换 3 条随机流重训后，满数据"蒸馏有害"扛住了、低数据那点好处被降级）；**拟合出来的"物理上限"报成带、不报成点**（同配置跑到 5 次，固定开销的跨度从 5.3pp **涨**到 5.8pp——带宽是当轮机器状态传导进截距的，加样本量救不了；跨运行真正稳的只有同轮比率，极差 2.8%）；**对照臂的统计量要先证明不退化**（ml-compress 第4课c：配平臂每个温度只有一个 α，"跨 α 极差"按构造恒为 0，第一版于是打印出"配平后 T 轴被压平 ⇒ 原假说借温度复活"这个反向结论，改成"钉回梯度换回多少伤害、与种子底比"才拿到正确判决——能算出 0 的差值不等于没有差；顺带一条：零训练探针推翻实验自身前提（α 与 T 对：许可证只数"同一批流被两本账各自算过一遍"的那些对，换一维独立性买到的是覆盖度不是对账。所以报数时**"在册几本"和"共对几对"必须分开写**，混起来说就等于声称买到了没买到的那种独立性）；**docstring 里的断言不是闸，实测打印出来的才是**（ml-compress 第4课h：一个新脚本的三道闸，我在注释里写"闸 B 不读键序，所以它看不见配对结构，`--unlink` 那一档只有闸 A 会红"——听起来是对自己实现的准确描述。真跑 `--unlink` 时它是**红 1 条**的：闸 B 的六个统计量确实照旧绿，但它比对"逐流序列"的那条子检查读的就是键序。半对半错的注释如果留着，下一轮读它的人会以为"B 永远管不到配对"，于是那档拆红也白拆。可执行的形式：**凡是"某道闸看不见 X""某种情况下不会红"这类关于自己代码的否定句，都要有一档模式把它跑成打印**，要么红要么绿，；**改口的界自己也带不确定度；而付完三段钱之后要检查的是「新阈值能不能被拆红」**（ml-compress 第4课f 第十二发把上一发记下的候选做成了 v5：倒挂那条腿从「份额>100%」改成「出界幅度 > 配对步长的 CI 半宽」。可迁移的形式有两层：**第一层是阈值本身**（「效应 > 它自己的 CI」而不是「效应 > 0」），**第二层是这条阈值也必须被拆红**——`--v5blind`（摘掉这条腿）与 `--v5strict`（半宽换成整个区间宽度）各钉一端，两档都红才说明「界开在哪里」是实现被约束着的，而不是「怎么写都算通过」。落地后『倒挂』从两个坐标缩到一个，而这次改口什么独立性都没买：**它买到的是判据自己的承重**，所以账上多出来的那句话是「什么读数才有资格叫倒挂」，不是「世界变了」）；**"每加一本账就重跑全部拆红"管的是强度，不只是计数**（ml-compress 第4课f 第十三发：那一档 `--drift` 上一轮红 4 条、本轮只红 1 条——退出码还是 1、名字还是那道闸，可是**它咬住的东西少了四分之三**。原因不在被注入的那个数上，在**挑注入点的规则**上：账册一涨，"老那本文件名排在新那本后面"这个条件能挑中的对就换了，同一档模式测到的其实是另一条更弱的性质。可迁移的形式：**拆红模式红"几条"要跟红"哪几条"一起重读**，只对齐总数=总数没变而牙齿已经掉了也查不出来；修法是让挑法与账册结构无关（这一轮改成挑"扩展出度最大的那本"，也就是同时是好几个对里一端的那本 hub），并且**每次挑中的对象要打印出来**，否则下一轮读文档的人以为同一档模式量的是同一条性质）；**档案里写着"核不到只能推定"的限制，先怀疑读的是哪一格**（ml-compress 第4课h：低数据那一对的配对前提一直记着"只核到 3/8，其余 5 条按同一构造推定"，而那句话是**检查读错了格子**造成的——CE 逐流读数本来就逐条躺在每一臂行的 `wrong_ce` 里，恒等闸那份名单只是它的 3 条抽样。换个取数来源即 3/8 → 8/8 整池核过，**零重训、零 API 费**。所以读到一条"这是客观限制"的 `limitations`，动手顺序是：先看那个量在盘上还有一条什么路径能拿到，再决定它是不是真的限制；同一条动作顺带把"覆盖不足如实报比例继续跑"升级成**当场退出**——限制一旦是读错格子造出来的，那个降级路径就没有理由存在）；**拆红档自己也会过期：只数退出码等于没测**（ml-compress 第十四发顺手回读第4课h：上一轮记在案的实测"关掉入口成员检查，那本换了成员的账照样被读进来"已经不成立了——新上线的 CE 缺读数检查会先把那本拦下，进程**照样 RC=1**。只看"退没退出"的拆红档永远不会发现这类回归，它看起来仍然像一次通过；而这一档的"红几条"本轮仍是同一个数，所以连上一条纪律也查不到它。修法有两半：把每一笔实测**打印成一句话**（在哪一道检查退出、为什么），再补一笔反向实测（成员一字不差、只把名单倒序 ⇒ 成员检查红而 CE 覆盖全绿）证明两道闸各管一段、互不顶包。可迁移的形式：**上线一道新闸，就要把所有旧拆红档重跑一遍，并逐笔核对"红在哪一道"，不是核对"红了几条"**）；**预演结构上走不到的分支，要在开跑前点名并补一档零成本预飞**（ml-compress 第十四发：`--nseeds 3` 那次预演压根到不了 `nseeds==16` 分支里的新代码——新种子池、`_n16` 后缀、"第 9~16 条是新买的"那行措辞，而上一轮的真实事故恰好是同一类（`KeyError: 12` 炸在 84 次训练之后）。所以固定动作升级为两层：先跑一个不训练的预飞脚本（核池前缀一字不动 / 系数表两把都在 / 档案名后缀按源码同一公式算出来给人眼核），**再在预登记里写清它仍覆盖不到的段落**（真正的训练循环与训练之后才执行到的判决打印）⇒ 第一次真跑就是那一段的活体预演，失败按"预演没覆盖"记，**不许记成"预演通过了却还炸"**。同一条纪律管墙钟：秒数没进档案就事后不可核，**宁可空着也不写一个自己记不起来的数**）
8. **负答案也要过承重这一关，而"买了几次密度"不许冒充"买了几条独立性"**（ml-compress 第4课f 第十六~十七发：同一句"倒挂在第二个任务上没出现"，在 8 条流下**不许说**——钉住它的那条配对步长是 +3.4 张 CI [−52.6,+59.4]，半宽 56.0 张比 MNIST 那条出界幅度（29.3）还宽 1.9 倍，"份额 93%"与"份额 130%"是同一把尺子容得下的两件事；补到 26 条流后半宽收到 25.1 张、第一次跨过预登记那道线，那句话才**第一次能按字面说**。可迁移的形式：**一个负结论的强度等于钉住它的那条步长的强度，不等于判词的字面**，与 v5 那条"别把噪声判成发现"同族而方向相反（这条管**别把没测动判成否证**）；同一条纪律反过来管合并记账：**这一发买到的三条答案全部出自同一个坐标的密度**（补流 ×3），一条新的独立性维度都没买，所以三发合并记时开头就要写明，而不是等读者把它们读成三条独立证据；**还有一条最容易漏的：一句话的"买没买过"要查名单和档案、不查记忆**——复现流名单原先在三个脚本里各有一份副本、外加一族 `NSEEDS == 8` 特判，于是"16 条流"这一档要么漏账要么写死；单点化成唯一来源（`FLOW_SEEDS` + `flows(n)` + `flow_tiers()`）之后，缺档流数在**任何训练之前**停住并点名"名单与系数必须一起长"（系数册 `D4`/`T95` 新档必须先用在册账复算对齐到 ±0.0005 才许入表），而**合并范围要如实圈出**：另外四个脚本仍各留一份，本轮没并进来 ≠ 已经并进来）
